# MitzuVPN 1.1.3

Telegram buttons inside the app open the Telegram app itself now, and the home and account screens received small fixes.

## Downloads

| File | For |
|---|---|
| `MitzuVPN-1.1.3-universal.apk` | **Android** 7.0 or newer, any phone |
| `MitzuVPN-1.1.3-arm64-v8a.apk` | Android, modern 64-bit phones (smaller download) |
| `MitzuVPN-1.1.3-armeabi-v7a.apk` | Android, older 32-bit phones |
| `MitzuVPN-Setup-1.1.3.exe` | **Windows** 10 or 11, 64-bit |
| `MitzuVPN-1.0.0-chromium.zip` | **Browser extension** (unchanged) |
| `SHA256SUMS.txt` | Checksums |

## New

- **Telegram opens the Telegram app.** The channel and support buttons now open Telegram directly instead of the browser — on Android and Windows. If Telegram is not installed, the browser opens as before.

## Fixed

- The connected screen names the server that is actually carrying the tunnel.
- Home remembers which quick-access card you were on, so going back lands where you left off.
- The subscription-link card for iPhone and other VPN apps no longer appears in the app.
