# MitzuVPN 1.1.2

A new connecting experience with a bubble animation and a redesigned connected screen, faster server-list updates with a clear result, and fixes for Auto (fastest), game servers and free locations.

## Downloads

| File | For |
|---|---|
| `MitzuVPN-1.1.2-universal.apk` | **Android** 7.0 or newer, any phone |
| `MitzuVPN-1.1.2-arm64-v8a.apk` | Android, modern 64-bit phones (smaller download) |
| `MitzuVPN-1.1.2-armeabi-v7a.apk` | Android, older 32-bit phones |

## New

- **A new connecting experience.** Pressing connect starts a bubble animation while the tunnel comes up, and the connected screen is redesigned: the server and protocol, the connection timer, live download and upload speeds and the total traffic, all at a glance.
- **Game servers are marked.** Locations whose server the panel marks as a game service carry a small **Game** badge in the list.
- **Operator names for free locations.** A free source that serves one country now appears in the app with the exact name the operator gave it.

## Fixed

- **Updating the server list** is faster, shows a spinner while it works and always reports the result: a confirmation when the list is up to date, an error when it could not be reached.
- **Auto (fastest)** re-runs the test every time you tap it, instead of reusing the previous result.
- **Free accounts** no longer show the subscription purchase section: subscriptions are provided through agents.
